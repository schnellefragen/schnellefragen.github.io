HelpHilfe

Frequently asked questionsHäufige Fragen

Short answers to what server admins ask most.Kurze Antworten auf das, was Server-Admins am häufigsten fragen.

Is schnellefragen free?Ist schnellefragen kostenlos?

Yes. Every feature is free, and there is no paid tier.Ja. Alle Funktionen sind kostenlos, eine Bezahlversion gibt es nicht.

Which permissions does the bot need?Welche Rechte braucht der Bot?

When you add the bot, Discord lists the permissions it asks for. Administrator is not one of them. Its role has to be above the roles it should hand out, such as the verification role or the roles in a role menu.Beim Hinzufügen zeigt Discord, welche Rechte der Bot anfragt. Administrator gehört nicht dazu. Seine Rolle muss über den Rollen stehen, die er vergeben soll, etwa der Verifizierungsrolle oder den Rollen eines Rollenmenüs.

Who can use which command?Wer darf welchen Befehl nutzen?

Moderation and setup commands only show up for members with the matching Discord permission, such as Ban Members for /ban. The command list names the permission for each command. Server admins can change this per role or channel under Server Settings → Integrations.Moderations- und Einrichtungsbefehle sehen nur Mitglieder mit der passenden Discord-Berechtigung, zum Beispiel Ban Members für /ban. Die Befehlsübersicht nennt die Berechtigung für jeden Befehl. Server-Admins können das je Rolle oder Kanal unter Servereinstellungen → Integrationen ändern.

Is the bot available in other languages?Gibt es den Bot auf Deutsch?

Not yet. The bot replies in English. This website is available in English and German.Noch nicht. Der Bot antwortet auf Englisch, diese Webseite gibt es auf Deutsch und Englisch.

What data does the bot store?Welche Daten speichert der Bot?

Only what its features need, such as settings, warnings and tickets. It does not store message content. When a server removes the bot, that server’s data is deleted after 30 days. Details are in the Privacy Policy.Nur, was die Funktionen brauchen, etwa Einstellungen, Verwarnungen und Tickets. Nachrichteninhalte speichert er nicht. Entfernt ein Server den Bot, werden dessen Daten nach 30 Tagen gelöscht. Einzelheiten stehen in der Datenschutzerklärung.

Logs or welcome messages stopped arriving. What now?Logs oder Willkommensnachrichten kommen nicht mehr an. Was tun?

Usually the bot can no longer post in that channel. The server owner then gets a one-time DM that names the missing permission. /log status and /welcome status show the problem in the server.Meist darf der Bot in dem Kanal nicht mehr schreiben. Der Server-Owner bekommt dann einmalig eine DM, die das fehlende Recht nennt. /log status und /welcome status zeigen das Problem im Server.

Where do I get help?Wo bekomme ich Hilfe?

Start with the guides. For personal help, open a ticket on the support server.Zuerst in den Anleitungen. Persönliche Hilfe gibt es per Ticket auf dem Support-Server.
