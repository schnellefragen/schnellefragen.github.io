## About this repository

This repository only hosts the static pages served by GitHub Pages. The pages are generated and uploaded as a whole, so changes made directly in this repository are overwritten by the next upload.

The website sets no cookies and loads no external fonts or scripts. Details are in the Privacy Policy.
